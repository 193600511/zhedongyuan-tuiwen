## 1. 全篇排版格式（硬规范）

| 项 | 要求 |
|---|---|
| 正文字号 | 17px（14px 小注/导语强调，12px 图注与落款；合法字号集 12–18px） |
| 字体 | 系统默认，**不得出现 font-family** |
| 行间距 | 1.75 |
| 字间距 | 0 |
| 图片段前/段后 | 8px（图片容器 margin:8px 0） |
| 首行缩进 | text-indent:2em |
| 对齐 | **成段文字一律 text-align:justify（两端对齐）**——右对齐/居中/左对齐的成段正文都是硬伤，auto_fix 自动归一；图注/落款居中不受影响 |
| 图片数量 | ≤10 张（只数真实照片，模板装饰图/gif 图标不计） |
| 禁用 | 纯黑 #000 文字色（用 #3e3e3e 系）、过多 !important、class="_editor" 残留 |
| 图片边框 | **头图（滑动 Logo / 校徽 gif）一律不加边框/描边**（2026-11-08 定）|
| 装饰边框 | **风景/时节类不套虚线、点线线条框**（正文段与图片都不要）——替代方案用历史实证样式：①文字块 = 米底卡 `background:#f5efe8;border-left:4px solid #b79481;border-radius:12px;padding:16px`（左竖线，源：秋染东方）②照片 = 白边相框 `padding:8px 8px 14px;background:#fff;box-shadow:0 4px 12px #0000001a`，宽 92% 居中 ③小节标题 = 同款米底色块 + 18px 加粗 #7a5c52（2026-11-08 定）|

342 篇历史推文实证：justify 342/342、letter-spacing:0 339/342、17px 正文主流。

> **术语口径**：上表里的英文属性名只在写代码、改 HTML 时用；**跟人说话一律说中文**——字号 / 字体声明 / 行距 / 字距 / 首行缩进 / 两端对齐 / 上下留白 8px / 背景图 / 底色 / 圆角 / 虚线框 / 强制优先级样式 / 编辑器残留标记。对照表见 SKILL.md「术语口径」。

## 2. 落款（固定结构，落款前与正文空开）

```
来 源 | 供稿部门（党校办/学工部/融媒体中心/教务处/招就处/人事处/各二级学院…）
编 辑 | 当期撰稿人本人（每篇不同，向用户确认姓名）
责 编（一审） | 孙舒
责 审（二审） | 吴昕灿
终 核（三审） | 武德力
```

- 党政新闻类可用「发 布 | 组织宣传统战部」替代「编 辑」行。
- 图文类可加「图 片 | 摄影者」「文 案 | 撰稿人」行。
- **落款五件套一律纯文本段落，颜色统一深灰 #3e3e3e**（2026-11-09 定，经 342 篇历史稿颜色实测校准）：字号 16px、字距 0、行距默认，不套底色、边框、圆角、装饰容器，前后不加装饰分隔线。颜色依据：历史落款主流 #222222（337+193 行）与 #3e3e3e（176+115 行）——都是深灰近黑，纯黑 #000 与浅灰 #888 均非口径。历史参照：顾宁阳稿。auto_fix 自动归一（计数键「落款去样式」，无色行补 #3e3e3e），体检提示「落款行带了历史口径外的样式」或「落款行未设颜色」。

## 3. 必含元素

1. **开头**：学校「滑动 Logo」校徽动图横幅（从往期文章复制，不在素材库时先向用户要）。
2. **结尾**：底部关注引导图（校徽+二维码+「长按识别扫码关注 订阅号：zjdfc1999」，从往期文章复制）。

## 4. 结构组件（assets/template.html 已内置）

**开头不设标题装饰块**（见 style-library §一 开头铁律）：正文从头图直接进导语，胶囊标签 / 大标题 / 副标题 / 装饰分隔线一律不放，标题填公众号标题栏。

正文结构：头图（滑动 Logo）→ 导语卡（左边框）→ 小标题×N（SVG：编号徽章与文字同字号 + 左右对称「线·点」装饰）→ 图文段（单图卡 / 双图拍立得微旋转卡）→ 金句（18px 左边框卡）→ END 分割线 → 落款 → 底部关注图。

配色随图片主题定：秋景暖棕 #7a5c52/#eaddd5、党建深红、夏景青绿等；模板中的色值按主题整体替换。

> 粘贴安全：出稿只用 `<section>`/`<p>`/`<img>` + 内联样式；不依赖 `background-image`（公众号编辑器会过滤）、不用 `transform:rotate` 做版式（粘贴后被掰正）、不靠 `flex` 承担主结构（降级即错位）。斜相框、信纸底这类效果改用实底色块 + 普通图片实现。

## 5. 文风五类（按稿型对号）

| 稿型 | 结构 | 落款特点 |
|---|---|---|
| 党政/会议新闻 | 导语点题→领导职务姓名→分段内容→意义升华 | 发 布 \| 组织宣传统战部 |

## 6. 标题风格

无标点直接拼接；固定栏目作前缀；通知类「XX你有一份XX请查收」；节日类对仗/谐音。不用绝对化表述（最/第一），不臆造领导姓名与数据。
