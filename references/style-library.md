# 浙东院推文样式库（342 篇存档实证）

> 数据来源：`D:/Desktop/推文/` 342 篇已发布文章，只统计 `js_content` 正文区。
> 出稿规则：**先判稿型（standards.md §5），再按本库对应稿型的真实风格出稿**；组件从 `assets/components/` 复制。

## 一、稿型 → 真实风格画像（实证）

| 稿型 | 占比特征 | 真实风格 | 出稿要点 |
|---|---|---|---|
| 新闻/会议/竞赛类 | 主流（约六成） | **素面**：无彩色卡片、无装饰组件。普通段落 + 图片直排 + 加粗行内小标题 | 正文纯 p/span，禁止卡片堆砌；小标题用「一、XXX」加粗独立行；图片居中直排 |
| 服务通知类 | 约 15% | 素面 + 分条列表（一、二、三 / 1. 2. 3.）+ 咨询电话收尾 | 条目用加粗编号，不套样式框 |
| 风景/时节类 | 约 10% | **96编辑器组件**：flex 双图/多图拼版（width:50% + margin-left:10px）、滑动图集、诗意短句 | 图片组件用本库 flex-two-images；文字短句分行居中 |
| 活动预告类 | 约 10% | **视觉靠设计切图**：主视觉、小标题条、时间地点卡都是 width:100% 整图；HTML 文字极短、居中、分行为主 | 向用户要切图；HTML 只做短句串场 |
| 人物系列类 | 少量 | 固定栏目「匠心榜样 技耀校园」，三段叙事 + 金句收尾 | 金句可加左侧竖线强调 |

**核心结论：学院真实画风以「素面正文」为主，彩色卡片/秀米风组件是少数。除非风景/活动类明确需要，默认走素面新闻风。**

**开头铁律（2026-11-05 用户确认）**：正文开头**不放**胶囊标签、大标题、副标题、装饰分隔线——标题填在公众号标题栏里，正文从「头图（滑动 Logo）→ 第一段导语」直接开始（342 篇存档一致）。出稿模板同理，任何稿型开头都不得加标题装饰块。

## 二、配色实证（正文区 js_content）

- 正文黑灰体系（素面稿）：`rgb(34,34,34)` / `#3e3e3e` / `#000000e4`，落款 `#888888`
- 学院蓝（通知/国际化/赛事）：`#205792` `#3c65ab` `#2870a8` `#105792`
- 党建红：`#c70000` `#7b0c00` `#c5363d` `#e20021`
- 暖橙强调（少量）：`#e36c09` `#e29a1e`
- 底色卡（少数风景/活动稿）：`#fbf6f3` `#dbeef3` `#eaf1fa` `#fff7f7`
- 白底 `#ffffff` 占绝对多数——**卡片底色不是学院惯例，慎用**

## 三、字号实证（正文区）

16px(5214) > 15px(2146) > 17px(2074) > 12px(1625 图注落款) > 14px(1371) > 18px(1183) > 20px(160) > 22/24px(89 标题)

- 历史稿正文 16px 为主流，但**现行采编部教程规定 17px**——出稿按教程 17px 执行（体检器也按 17 查）
- 强调/金句 18px；小标题条目加粗 17px；图注落款 12px

## 五、历史样式组件库（assets/components/gallery/，2026-11-05 V3 纯样式版）

对 356 篇存档做组件级挖掘 V3：**所有层级**带样式节点配平截取 →「结构+样式」指纹去重（抹文字/src，同款样式不同文字合并）→ 清洗孤立闭合+补缺失闭合（**保留标签间文字**）→ 过滤：微信挂件（作者头像/二维码/关注条）、照片 `<img>`、背景切图 `url()`、空壳占位段（无文字无图形无背景）、残缺 SVG 片段 → 共 **403 个**纯样式组件（全部带真实示例文字），存于 `assets/components/gallery/`（001~403 编号 + index.json 索引）。

分类分布：text 文字样式（落款/图注/字色字号）236 · block 色块/强调框 151 · card 卡片框 12 · cut-gradient 纯CSS渐变 2 · svg-art 纯SVG装饰 2。

**重要实证**：①学院复用组件时每篇都会换主题色——正确用法是「取组件结构 → 把颜色值换成当稿主题色」；②最高频样式是落款族（「来 源|」「编 辑|」「责 审（二审）| 吴昕灿」12px #888 灰字，148 篇）；③9成历史 SVG 装饰内嵌图片，属切图类，未入本库。

**出稿用法**：
1. 从 gallery 按 category 挑结构合适的组件，替换示例文字、颜色改主题色。
2. 可视化浏览：工作区 `style-mining/样式库预览.html`（403 个组件全量画廊，真实渲染）。
3. 挑选后仍须过 `check_article.py` 体检。

**注意**：正文段落参数以采编部教程 17px 为准，组件只作标题/卡片/分割装饰；切图类组件的 background-image 是微信 CDN 图（mmbiz.qpic.cn），粘贴进微信编辑器可直接显示。
